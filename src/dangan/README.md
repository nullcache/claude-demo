# 弹丸论破 · 20 秒游戏 PV（同人致敬）

> 粉丝向非官方作品。黑白熊、学生剪影等全部为原创矢量重绘，未使用任何官方素材。

## 概念

**一条裂缝，两种颜色。** 开场的锯齿裂缝把画面劈成「希望（白）| 绝望（黑）」，镜头拉远后这条裂缝变成黑白熊脸上的分界线。到了结尾，同一条裂缝把主标题拆成 `弹丸 | 论破`、`DANGAN | RONPA`、`希望的学园 | 绝望的高中生`，裂缝本身就是“与”。

**一颗伏笔，一发言弹。** 第 3 小节插入镜头「所有窗户 · 被铁板封死」，到第 6 小节变成议论中的弱点「窗户」，再到第 7 小节成为装填的言弹「铁板封死的窗户」，最终在「那是错的！」处击碎。20 秒里，一个完整的学级裁判推理形成了闭环。

## 视觉系统

- **色彩**：墨黑 `#0A090D` / 纸白 `#F6F3EE` / 粉血 `#FF2D7E` 为主轴；弱点与言弹用黄 `#FFD31A`；只有黑白熊的眼睛用红 `#F0122D`。
- **字体**（SIL OFL，按片中用字子集化并改名）：思源黑体 Black（标题）、思源宋体 Black（校名、副标题）、站酷庆科黄油体（拟声字）、Anton（英文标签）、Press Start 2P（像素画面）。
- **质感**：程序生成的胶片颗粒（30fps 更新）、扫描线、暗角、半调网点、漫画集中线。

## 制作

```bash
npx remotion studio src/index.ts          # 预览（合成名 DanganPV）
npm run dangan                            # 渲染 → out/dangan-pv.mp4（1920×1080 · 60fps · H.264 + AAC）
npm run dangan:audio                      # 重新合成配乐 → public/dangan/score.m4a（需 numpy / scipy）
npm run dangan:fonts -- <源字体目录>       # 改了片中文字后重新子集化字体（需 fonttools）
```

| 文件 | 内容 |
|---|---|
| `core.ts` | 节拍网格、色板、缓动、震屏与闪帧表 |
| `ui.tsx` | 文字（立体挤出 / 色差）、集中线、半调、血迹、玻璃碎裂、弹孔裂纹、HUD |
| `chars.tsx` | 黑白熊、8 种学生剪影、像素精灵 |
| `Act1.tsx` / `Act2.tsx` / `Act3.tsx` | 12 个镜头 |
| `DanganPV.tsx` | 镜头调度、全局震屏、颗粒 / 扫描线 / 暗角、显像管关机 |
