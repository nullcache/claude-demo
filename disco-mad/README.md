# 极乐迪斯科 × Пачка сигарет（v2）

成片：`release/disco_mad_v2.mp4`。1920×1080、30fps，时长约 67 秒。
音乐：LIZER – Пачка сигарет（B 站 BV1QHb16dE6x），截取 37.9s–104.8s。

## 立意

这首歌唱的是一个人守着一包烟过日子：
- "我的朋友就是我的香烟"；
- "是它让我撑过今天"；
- "妈妈，我为什么想死"。

哈里在游戏开局就是这个状态。

整片的结构是：**两段副歌歌词一字不差，画面给出两个不同的回答。**

| 段落 | 歌词（大意） | 画面 |
|---|---|---|
| 前奏 / 主歌 | 烟抽不完，墙压得喘不过气，在寒冷里睡去，窗开着，"我在等一点温暖" | 哈里趴在旅馆地板上醒来；电化学人格；领带；被隔离的房间；倒下；古老爬虫脑的黑屏独白；碎窗。唱到"等一点温暖"时，楼下的金出现 |
| 过渡 | 我的朋友就是我的香烟 / 我们永远不会分开 | 电化学和金的肖像每 2 拍交替一次；Kineema 旁的两人，金说"很高兴认识你，哈里尔·杜博阿。" |
| 副歌一 | 口袋里一包烟 / 撑过今天 / 打给妈妈 / 为什么想死 | 只有哈里：油画面孔逐拍冲击；思维阁油画 1 拍切 1 张，表现荒诞的人格轮盘；金说"那种母亲会在乱世给儿子起的名字"；Suicide is painless |
| 副歌二 | 同样的歌词 | 换成金：雪地上的两人；"你能继续吗？"；"我从来没见你哭过，也没把我的手帕借给你擦过眼泪"；"来41分局工作。" / "我受宠若惊……" |
| 尾声 | 窗外下雨，心还在跳 / 这首歌唱的是什么 / 也许明天太阳会出来 | 雨夜的 Kineema；卡拉OK；教堂舞池；冰海小船；瑞瓦肖日出配"春天来了。到时间了。"；两人走向 Kineema |

画面不做调色，保留游戏原色。不做强行搞笑，荒诞感只来自游戏本身的素材。

- **B 站金·曷城片段合集**（BV1Wy4y147V1）：用了第 3、5 P。

- **Disco Elysium Wiki（Fandom）官方美术**：角色肖像、思维阁油画、技能人格画、Kineema 插画、瑞瓦肖全景。
- **台词**：来自游戏中文版画面。歌词的中文译文是我自己翻译的。

## 迭代方式

```bash
pip install opencv-python-headless pillow numpy librosa yt-dlp
./fetch_media.sh                 # 重建 media/ 和 fonts/（不入库）
python3 render.py --sheet        # 每个镜头中点出一张静帧 -> out/stills/
python3 render.py --still 64.5   # 指定歌曲时间出静帧
python3 render.py --range 60 75  # 局部渲染
python3 render.py                # 全片 -> out/disco_mad.mp4
```

- `timeline.py`：分镜表。时间都用"歌曲时间"表示，`at(k, j)` 表示第 k 句歌词的第 j 拍，每句 8 拍，约 152 BPM。改镜头只需要改这个文件。
  - `vid()`：视频镜头。`img()`：图片镜头。`quote()`：游戏式台词，带打字机效果。
  - `cam0/cam1 = (cx, cy, zoom, rot)`：镜头起止机位。
  - `punch`：逐拍冲击缩放。
  - `fx`：`flash` 闪白、`fadein`/`fadeout` 淡入淡出、`darken` 压暗、`rgbsplit` 色散。
- `engine.py`：合成器。负责机位变换、文字排版和特效。
- `render.py`：逐帧合成，通过管道交给 ffmpeg 编码，同时混入音频。
- `research/song-research.md`：选曲调研。
